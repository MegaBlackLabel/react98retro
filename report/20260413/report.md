# Windows 98 実画面との突き合わせ（react98retro）

- 対象: `react98retro` のデモ（ファイルエクスプローラー）
- 方法: 実機スクリーンショットを**画素で計測**し、当方の実装を headless Chromium の
  computed style / `getBoundingClientRect` で計測して突き合わせた
- 制約: 画像を目視できないため、**「見た目」ではなく数値（色・寸法）での比較**に限定。
  参考画像はパレット変換で色が劣化している箇所があるため、色の比較は
  「同じであるべき色が一致するか」の確認に留めた。

## 参考にした実画面

| 用途 | 出典 |
|---|---|
| デスクトップ / タスクバー | GUIdebook > Windows 98 SE > Empty desktop (`pics/gui/desktop/empty/win98se.png`) |
| ウィンドウ枠・タイトルバー・メニューバー | 同 > File manager (`pics/gui/system/managers/filemanager/win98se.png`) |
| ステータスバー | 同上 |
| スクロールバー・3D 部品 | 98.css (`node_modules/98.css/dist/98.css`) の実装値 |

計測は Python (Pillow) の使い捨てスクリプトで実施した（画素の境界を列/行走査で出す。リポジトリには含めない）。

1. **タスクバー一式**（28px + Start 54x22 + タスクトレイ + 時計）— 未実装の中で最も目立つ。

### 追加対応 (2026-10-13)

- **日本語 UI の文字サイズを 12px に統一**: 日本語版 Windows 98 の UI は MS UI Gothic 9pt = 12px。
  MS UI Gothic のビットマップは 12px 用なので 11px では行内で潰れて汚く見える。
  98.css 由来 (英語版 11px) と自作 CSS の 11px を 12px に揃えた
  (ピクセルフォントも 12px の方が輪郭が綺麗: 中間色ピクセル 45%→35%)。
- **スタート ボタンの折り返しを修正**: 幅 54px 固定 + white-space: normal で「スタート」が 2 行になっていた。
  54px を最小幅にして折り返し禁止 (日本語ラベルで 62x22)。

### 追加対応 2 (2026-10-13): 文字のにじみ解消

ウインドウ内の文字がにじむ件。実測 (アンチエイリアスの中間色ピクセル率):

| フォント | にじみ |
|---|---|
| Pixelated MS Sans Serif 11px | 43.2% |
| 同 12px | 42.0% |
| MS UI Gothic 12px | **0%** |
| ピクセル→MS UI Gothic (旧構成) | 29.3% (英数だけにじむ) |

ピクセルフォントは輪郭フォントのため Chromium では常にアンチエイリアスが掛かり、
MS UI Gothic は 12px のビットマップを持つため 0% (ドット通りシャープ) になる。

- フォントスタックを **MS UI Gothic 優先**に変更 (MS PGothic → Pixelated MS Sans Serif → DotGothic16 にフォールバック)
- 98.css 由来・自作 CSS の両方に適用。メニュー文字のにじみは 40% → **6.6%** に低減
